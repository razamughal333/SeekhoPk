# Image slots

Drop real image files here with these exact names, and they'll appear
automatically — no code changes needed. Until a file exists, that spot
shows a themed teal/saffron stripe pattern instead of a broken image.

| File                  | Used on          | Suggested size    |
|------------------------|-------------------|--------------------|
| hero-banner.jpg        | Home page banner  | 1600x500px, landscape |
| auth-side.jpg           | Login/Register    | 900x1200px, portrait |

Course cover images are NOT static files — they're pasted as a URL
when creating/editing a course (any image URL works, including free
stock sites like unsplash.com or pexels.com, or your own uploaded image).

Formats: .jpg or .png both work. Keep each file under ~500KB so pages
load quickly — resize/compress before dropping in if needed
(squoosh.app is a free, quick option).
